## 🚀 Key Features

### 👨‍💼 Admin Portal (Management Hub)
*   **Comprehensive Dashboard:** High-level overview of total staff, active tickets, and asset health.
*   **Staff Management:** View and manage employee records and roles.
*   **Asset Inventory:** Track laptops, monitors, and peripherals assigned to staff.
*   **Support Tickets:** Centralized hub to view, update, and resolve IT issues raised by staff.
*   **Inspection Tracking:** Monitor upcoming and overdue equipment inspections.

### 🧑‍💻 Staff Portal (Employee Self-Service)
*   **My Assets:** Employees can view their assigned equipment and check inspection statuses (Healthy, Due Soon).
*   **My Tickets:** View a history of open and resolved IT issues.
*   **Raise a Ticket:** A beautifully designed modal allowing staff to report issues, add detailed notes, and upload screenshot attachments.

## 🛠️ Technology Stack

*   **Framework:** Next.js 14 (App Router)
*   **Language:** TypeScript / React
*   **Styling:** Tailwind CSS
*   **Animations:** Framer Motion (Spring physics & exit animations)
*   **Icons:** Lucide React
*   **Deployment:** Vercel

---

## 🧠 Design Philosophy
The goal was to move away from clunky, traditional enterprise software and build an internal tool that feels like a modern SaaS product. By utilizing **Framer Motion** for micro-interactions and **Tailwind CSS** for a clean, whitespace-heavy design, VSS provides a frictionless experience for both everyday staff and system administrators.
